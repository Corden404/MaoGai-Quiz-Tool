# 题目标签组合筛选设计

## 目标

将“错题巩固、星标练习、重点练习、难记练习”从互斥的刷题模式中剥离，新增独立的“4. 题目标签”筛选区域，让用户能够一次练习命中任一所选标签的题目。

## 页面结构

### 3. 刷题模式

刷题模式只负责题目队列的组织方式，保留：

- 顺序练习
- 随机抽题
- 全网易错

随机抽题数量和全网易错最低错误率继续显示在刷题模式区域，并仅在对应模式选中时出现。

### 4. 题目标签

新增与现有选择卡片视觉一致的题目标签区域，包含：

- 所有题目
- 错题巩固
- 星标练习
- 重点练习
- 难记练习

默认选中“所有题目”。“错题次数 ≥ N”输入框移动到题目标签区域，并仅在“错题巩固”被选中时显示。

## 选择规则

- 题目标签始终至少选择一项。
- “所有题目”与其他四项互斥。
- 选择“所有题目”时，清除其他标签。
- 选择任一具体标签时，自动取消“所有题目”。
- 错题、星标、重点和难记可同时选择。
- 当用户尝试取消最后一个具体标签时，自动恢复为“所有题目”，不产生空选择状态。

## 筛选语义

筛选顺序为：

1. 根据已选章节和题型得到基础题目集合。
2. 根据刷题模式处理全网易错集合，或保留本地基础集合。
3. 应用题目标签筛选。
4. 若为随机抽题，则打乱筛选结果并截取指定数量。

“所有题目”不增加标签过滤。选择多个具体标签时使用 OR 语义：题目只要满足任一条件就进入队列，并且同一道题只出现一次。

具体条件为：

- 错题巩固：`error_count` 大于或等于用户设置的最低错题次数。
- 星标练习：`tag_star` 为真。
- 重点练习：`tag_key` 为真。
- 难记练习：`tag_hard` 为真。

刷题模式和标签可以组合。例如：

- “随机抽题 + 错题巩固 + 星标练习”会从错题或星标题中随机抽取。
- “全网易错 + 重点练习 + 难记练习”会保留全网易错题中同时属于重点或难记的题目。

如果组合筛选后没有题目，沿用现有“没有找到符合条件的题目”提示，不进入答题页面。

## 状态与代码边界

- `mode` 只保存 `sequence`、`random` 或 `global_mistake`。
- 新增题目标签选择状态，默认值为仅包含“所有题目”。
- 标签选中状态切换和题目标签过滤提取为独立、无副作用的辅助函数，便于自动化测试。
- Vue 页面负责展示状态、响应点击以及将筛选结果交给现有队列流程。
- 不改变题目本身已有的星标、重点和难记标记数据结构，也不迁移用户数据。

## 选择摘要与引导

- 选择摘要同时显示当前刷题模式和已选题目标签。
- 多个具体标签使用清晰的分隔方式列出。
- 页面引导中的刷题模式说明同步更新，并增加题目标签步骤说明。
- README 中关于专项练习的描述更新为可组合标签筛选。

## 测试

自动化测试至少覆盖：

- 默认状态为“所有题目”。
- 选择具体标签会取消“所有题目”。
- 选择“所有题目”会清除具体标签。
- 取消最后一个具体标签会恢复“所有题目”。
- 多个具体标签按 OR 语义筛选。
- 同时命中多个标签的题目不会重复。
- 错题最低次数正确参与 OR 筛选。
- 标签筛选可与顺序、随机和全网易错模式组合。
- 摘要和页面结构不再把四个具体标签列为刷题模式。

浏览器交互验证覆盖：

- 桌面和移动宽度下的四步选择区域布局。
- 标签互斥和多选反馈。
- 错题次数输入框的条件显示。
- 组合筛选后的题目队列与摘要。
- 浅色和深色主题下的选中状态。

## 非目标

- 不增加 AND 标签匹配模式。
- 不持久化用户在设置页选择的筛选组合。
- 不改变答题页面上的星标、重点和难记按钮。
- 不改变用户进度、错题次数或标签的云端存储格式。
- 不重构与本功能无关的答题、导出或账号逻辑。
