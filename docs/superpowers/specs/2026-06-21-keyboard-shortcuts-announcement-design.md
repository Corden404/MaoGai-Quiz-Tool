# 键盘快捷答题更新公告设计

## 目标

在现有更新公告列表顶部加入一则面向普通使用者的公告，介绍键盘快捷答题功能及使用方法。

## 公告信息

- 版本：5
- 类型：更新公告
- 标题：`⌨️ 键盘答题更方便了`
- 日期：`2026-06-21`

## 公告内容

沿用此前更新公告的三卡片样式：

1. **快捷选择选项**
   - 按键盘上的 `A / B / C / D`，即可快速选择对应选项。
   - 再按一次相同按键，可取消已选选项。
2. **一键提交答案**
   - 选好答案后按 `Enter`，即可立即提交。
   - 提交后仍停留在当前题，方便查看答案和解析。
3. **输入时不会误触**
   - 输入笔记或文字答案时，快捷键不会影响正常输入。

文案只描述使用方法和体验，不出现代码、事件监听、状态判断等开发术语。
