# 思政刷题助手

思政刷题助手现已上线，支持题目练习、智能刷题、进度同步和错题复习，帮助你更高效地备考。

👉 **[点击这里在线体验网站：scau-test.top](https://scau-test.top)**

![Icon](icon.png)

## 🌟 核心功能

### 📚 双科目题库

- 支持《毛泽东思想和中国特色社会主义理论体系概论》(毛概) 与《马克思主义基本原理》(马原)。
- 两个科目的练习进度、错题记录和标记数据相互独立。
- 可在页面内快速切换科目，不需要重新打开页面。

### 🧠 智能刷题模式

- 支持按章节、题型筛选题目，适合分阶段复习。
- 提供顺序练习、随机抽题和全网易错等刷题模式。
- 错题、星标、重点和难记标签可同时选择，一次练习所有命中任一所选标签的题目。
- 全网易错模式可根据题目错误率筛选高频易错题，集中练习更有针对性。

### ✅ 答题与复习

- 客观题自动判分，答完即可查看正确答案。
- 主观题支持自评，适合简答题、论述题等开放题型。
- 错题会自动记录，可按错题次数和复习范围重新练习。
- 支持查看历史练习状态，快速回到未掌握的题目。

### ☁️ 进度同步

- 登录后可同步刷题进度，多设备之间继续练习。
- 本地缓存会保存当前练习状态，降低刷新或临时退出带来的进度丢失。
- 不同科目、不同题目的完成情况会分开记录，复习路径更清晰。

### 📝 笔记与解题广场

- 每道题提供参考解析，帮助快速理解考点。
- 可以为题目记录个人笔记，沉淀自己的记忆方法。
- 支持在解题广场查看和分享笔记，参考其他同学的解题思路。
- 笔记支持点赞和热度排序，优质内容更容易被看到。

### 📤 错题导出

- 支持导出错题、星标题、重点题和难记题。
- 可按章节、题型、错题次数等条件整理导出内容。
- 支持 PDF、Markdown、TXT 多种格式，方便打印、整理或二次编辑。
- 可选择只导出题目、题目加答案，或包含个人笔记的完整版本。

### 🔒 隐私与数据说明

- 个人练习进度、错题记录和私有数据会按用户隔离。
- 公开分享的笔记会展示在解题广场中，未分享的个人内容不会公开。
- 更多说明请查看 [隐私与免责声明](privacy.html)。

## 🛠️ 技术概览

项目基于 **Vue 3 + Tailwind CSS + Supabase** 构建，整体保持轻量级纯前端形态。Supabase 用于提供用户认证、云端进度同步、公共笔记和全网易错统计等能力。

- 想集中刷错题、重点题和高频易错题的同学。
- 想在多设备之间同步练习进度的同学。
